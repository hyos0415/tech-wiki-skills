# 기술 조사 위키

## 이 위키의 질문

Claude/GPT와 나눈 기술 조사·학습 대화를 어떻게 개인 자산(Cards)으로 정리하고,
필요하면 공개 블로그 글(Blog-drafts)로 승격할 것인가?

## 폴더 역할

- `raw/` : 원본 대화 텍스트 보존 (수정하지 않음)
- `Scratch/` : 1단계 탐색노트 + 팩트체크·휴머나이즈 중간산출물 (임시, git 추적 제외)
- `Cards/` : 2단계 자산화 카드
- `Blog-drafts/` : 3단계 블로그 초안 (윤문본도 같은 파일에 덮어써서 반영)
- `Templates/` : 카드 템플릿 원본

규칙은 `CLAUDE.md` 하나에만 있다. 이력은 `log.md`에 쌓인다.
